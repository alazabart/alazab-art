# Roadmap

## Professional file gallery (ALAZAB Files)
- [ ] Database: projects, members, folders, documents, versions, approvals, share links, audit log + access rules
- [ ] Private file storage with per-project access
- [ ] Sign-in / sign-up / password reset for staff and clients; first account becomes admin
- [ ] Gallery shell: Home, Projects, Gallery, Approvals, Shares, Archive, Users (admin)
- [ ] Project explorer: folders tree, grid/list, upload with type check + checksum
- [ ] Document page: preview (image/PDF/video/Office/3D), metadata, versions, approvals, share links
- [ ] Public share page with expiry/revocation
- [ ] Link the gallery from the gateway
- [ ] Later: version comparison, AI classification
